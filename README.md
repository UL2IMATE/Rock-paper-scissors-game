# Rock Paper Scissors Game

A simple browser-based Rock Paper Scissors game built with HTML, CSS, and JavaScript. The player competes against the computer by choosing one of three options: Rock, Paper, or Scissors.

## Description

This project is a fun and beginner-friendly web game that demonstrates basic DOM manipulation, event handling, and random logic in JavaScript. It is lightweight, easy to run, and does not require any external libraries or setup.

## Features

- Play against a random computer opponent
- Score tracking for both player and computer
- Instant result messages after each round
- Responsive and visually appealing layout
- Lightweight project with no dependencies

## How to Play

1. Open the game in a web browser.
2. Click one of the buttons: Rock, Paper, or Scissors.
3. The computer will randomly choose its move.
4. The result will be displayed, and the score will update automatically.

## Rules

- Rock beats Scissors
- Paper beats Rock
- Scissors beats Paper
- If both players choose the same option, it is a draw

## Project Structure

- index.html — main HTML structure
- style.css — page styling and layout
- script.js — game logic and score updates
- webfonts/ — font assets used by the project

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone the project.
2. Open the index.html file in your browser.
3. Start playing immediately.

## Example

- Player chooses Rock
- Computer chooses Scissors
- Player wins the round
